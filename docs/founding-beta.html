What you get

Private Python 3.11+ Action Guard package for trusted local scripts and cooperatively routed AI command workflows. Durable SQLite attempt limits, command wrapper, status inspection, and a documented STOP exit code. Founding updates through v1.

What it isn't

Not a hosted SaaS, code sandbox, global policy service, authenticated human approval, spend billing service, or universal control over arbitrary agent actions. The trusted local owner can always bypass the wrapper.

Free alpha versus Founding Beta

The free public alpha shows a fixed browser demonstration with Attempt Lock and simulated Spend Lock. The Founding Beta Action Guard adds a genuine command-line adapter for running your own local commands through finite Attempt Lock authority. The separate Spend Lock provider gateway remains experimental.

Who is this for?

Developers who own the command execution path on a trusted machine and can route their automations through the wrapper. You must use the same persistent database and stable task/action identity across invocations.
