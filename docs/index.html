EXTERNAL DEVELOPER ALPHA · v0.2.0

Give an AI agent
a finite wallet.

MeterLock is a local spend-control gateway for unattended AI runs. It reserves budget before generation, then blocks requests that no longer fit inside the wallet you authorised.

Test the alpha See the 10-minute test

Async testing only. No calls. No meetings. Use a dedicated low-limit OpenAI key and tiny test wallets.

01

Create a wallet

Set a budget and expiry for one specific agent or run.

02

Hand over a scoped key

The agent receives a MeterLock key tied to that wallet — not your upstream provider key.

03

Stop spend before generation

Budget is reserved before forwarding. If the request will not fit, generation is refused.

04

Pause, resume, revoke

Pause temporarily, resume when ready, or revoke the scoped key permanently.
